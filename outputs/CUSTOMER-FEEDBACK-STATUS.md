## Operational limits

All product services remain local. Monitoring stops when the service or laptop stops. There is no cloud deployment. Google testing-mode consent may expire and require reconnection. This is a development connection, not a production verified OAuth integration.

The browser test targets the current preview; do not change the same Lovable project externally during a test. Only the checklist-editing profile is automated. Needs-review states require an operator to inspect remote state before recovery. HTML-only emails currently need a text/plain part.

Worker integration tests must run while the workflow service is stopped; they acquire its advisory lock and refuse to run alongside it. The normal API integration suite needs the service running.
